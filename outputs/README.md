# Analysis Outputs

This folder is generated by `scripts/analyze_je_samples.py`.

Expected files:
- `summary.json`: Core summary stats (row counts, date ranges, missing values).
- `summary.md`: Markdown summary with quick highlights.
- `column_profile.csv`: Column-level missingness and data types.
- `numeric_describe.csv`: Descriptive statistics for numeric columns.

Run the script locally or via the GitHub Actions workflow to refresh these outputs.
